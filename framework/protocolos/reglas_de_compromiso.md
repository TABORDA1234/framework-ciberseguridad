# Protocolo de Seguridad y Reglas de Compromiso (RoE)

1. Prohibido subir credenciales reales o tokens activos.
2. Ejecutar pruebas únicamente sobre activos autorizados.
3. Verificar integridad de evidencias mediante SHA-256.
4. Emplear plantillas neutras y lenguaje seguro en pruebas de Prompt Injection (MITRE ATLAS AML.T0051).
