# Glosario Técnico y Metodológico

- **Red Team**: Equipo o función que emula comportamientos adversarios bajo autorización.
- **Blue Team**: Función encargada de protección, detección y respuesta.
- **Purple Team**: Colaboración sistemática entre actividades ofensivas y defensivas.
- **DFIR**: Forense digital y respuesta a incidentes.
- **OSINT**: Obtención y análisis de información de fuentes abiertas.
- **DNSSEC**: Extensiones de seguridad DNS basadas en firmas criptográficas.
- **Prompt injection**: Instrucciones maliciosas destinadas a alterar el comportamiento previsto de un sistema LLM (OWASP LLM01:2025).
