# Definición y Fundamentación de FC-USTA

`FC-USTA` integra procedimientos ofensivos (Red Team), defensivos (Blue Team), forenses (DFIR) y colaborativos (Purple Team) para identificar, analizar, evaluar, mitigar y verificar riesgos de ciberseguridad en infraestructura, aplicaciones web, factor humano y modelos de IA (LLMs).
